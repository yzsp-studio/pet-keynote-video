## 🇨🇳 中文

把同一只宠物的照片做成 28 秒极简科技发布会风格的写实概念短片。产出五款服装参考图、15 秒与 13 秒两段无音轨视频，以及拼接后的 28 秒成片。两段视频始终要求静音生成，每次返回后检查实际音轨，若仍带音轨则只移除音轨、保留画面分辨率帧率与时长不变，画面分别验收后才拼接成无音轨母版并合成用户指定 BGM 或保持静音。宠物保留原照中的脸、口鼻、耳朵、毛发、尾巴和天然体型，动作按实际解剖适配，包含悬挂工装外套贴袋、双宠互动与对称好奇歪头等指定造型与切镜。任何图片或视频生成前都必须确认具体分辨率，不默认采用 2K 或模型默认值。不冒充官方品牌作品、不加品牌标志或官方背书，也不用于幻灯片。

- 音轨真校验：逐次检查文件是否真的无音轨，纯去音轨且不改画面规格
- 生成前强制确认分辨率，不静默升降级，返回后核对实际像素与画幅
- 广告文字保留中文原文，仅替换宠物名称与品种，不作对白字幕
- 身份一致性：保留脸、毛色、花纹与体型，动作按实际解剖适配

## 🇬🇧 English

Turns photos of one pet into a 28-second realistic concept short in a minimal tech-launch style. It delivers one five-outfit costume reference image, a 15-second and a 13-second silent video, and the assembled 28-second film. Both segments are generated silent, and every returned file is checked for a real audio track; if one remains, only the audio is stripped while picture, resolution, frame rate and duration stay untouched, after which each segment is reviewed, joined into a silent master and scored with the user's chosen BGM or left silent. The pet keeps its original face, muzzle, ears, fur, tail and natural build from the photo, with movement adapted to real anatomy, and includes the hanging work-jacket patch pocket, two-pet interaction and symmetrical curious head tilt. Resolution must be explicitly confirmed before any image or video generation, with no silent fallback to 2K or model defaults. It never impersonates an official brand, adds no brand marks or endorsement, and is not a slide deck.

### ✨ What it does

- Pet photo to a five-outfit costume reference image in a consistent 16:9 landscape format
- 28 seconds split into a 15-second and a 13-second silent master, scored with the chosen BGM only after picture approval
- Real audio-track verification: every returned file is checked for sound, and stripping audio never changes the picture specs
- Resolution must be confirmed before generation with no silent up- or downgrade, and actual pixel size and aspect are re-checked on return
- On-screen ad copy keeps its original Chinese wording, swapping only the pet name and breed, and is not treated as subtitles
- Identity consistency: face, coat colour, markings and build are preserved, with movement adapted to real anatomy
